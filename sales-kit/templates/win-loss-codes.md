# Win / Loss Reason Codes

Use exactly one primary code per closed opportunity. Add a secondary code if needed.  
Review monthly; feed battlecards and ICP filters.

## Wins

| Code | Meaning |
|------|---------|
| W-EXCL | Won exclusive distribution |
| W-LIM | Won limited-network seat |
| W-HUB | Won integrated SP + hub scope |
| W-REL | Won primarily on executive relationship / trust |
| W-DATA | Won on data / transparency / technology |
| W-CLIN | Won on clinical / rare-care depth |
| W-TRANS | Won displacement / transition from incumbent |
| W-CONS | Consulting engagement converted to distribution |

## Losses

| Code | Meaning |
|------|---------|
| L-PBM | Manufacturer required PBM-owned SP |
| L-INCUMB | Incumbent retained (switching cost) |
| L-PRICE | Lost on dispensing fee / commercial terms |
| L-SCALE | Lost on perceived scale / capacity |
| L-BRAND | Lost on competitor brand recognition |
| L-TIMING | Too late — network already locked |
| L-FIT | Asset / channel model not VRP ICP |
| L-RFP | Process loss (scoring, politics, incomplete response) |
| L-SILENCE | Ghosted / no decision after mutual engagement |
| L-COMPLIANCE | Failed security / compliance / contracting hurdle |

## Hygiene rules

1. No win/loss without a code within 5 business days of close.  
2. Losses coded `L-PRICE` require deal desk note: floor terms offered vs. winner (if known).  
3. `L-TIMING` should create a recycle task at next label/indication catalyst.  
4. Three identical loss codes in a quarter → strategy review, not more activity.
